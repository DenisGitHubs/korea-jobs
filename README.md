# korea-jobs — «Работа в Корее»

Telegram Mini App: вакансии для рабочих в Южной Корее, собранные из десятков
телеграм-чатов в одну ленту с фильтром по городу, визе и виду работы.

**Открыть:** [t.me/korea_rabota_bot/app](https://t.me/korea_rabota_bot/app) ·
бот [@korea_rabota_bot](https://t.me/korea_rabota_bot)

Живой личный проект: приложение работает, им пользуются люди. Объявления —
из открытых источников; работодателей мы не проверяем и стороной сделки не
являемся.

## Как это устроено

```
телеграм-чаты
     │  читалка (GramJS, отдельный worker на DigitalOcean)
     ▼
raw_messages ──► пре-фильтры (спам, дубли, «не вакансия») ──► ИИ (Claude Haiku)
                                                                    │
                                              разбор по полям, город, виза, зарплата
                                                                    ▼
                                                               vacancies
                                                          │              │
                                              мини-апп (лента)      бот (уведомления)
```

- **Читалка** живёт отдельно от веба: у неё есть только сессия Telegram и ключ
  на приём — ни базы, ни токена бота.
- **Пре-фильтры до ИИ** — дешёвые правила, отсекающие мусор: платные «услуги
  трудоустройства», рубли вместо вон, повторы по хэшу текста. ИИ вызывается
  пачками и только на то, что прошло фильтры.
- **Разбор** даёт структуру: город (справочник + разрешение по контексту),
  вид работы, виза, зарплата с валютой и периодом, пол, жильё, питание.
- **Уведомления** — только по явной подписке, с лимитом в сутки на человека.

## Что внутри

| Папка | Что там |
|---|---|
| `app/` | мини-апп: React + Vite + `@telegram-apps/sdk-react` |
| `api/` | один catch-all роутер для Vercel (`api/index.ts`) |
| `lib/korea/` | бэкенд: auth по initData, лента, бот, разбор, уведомления, рефералка, модерация, юр-обвязка |
| `collector/` | читалка чатов (Node + GramJS), отдельный worker |
| `db/` | миграции (`db/migrations/draft_*.sql`) и `db/apply.mjs` |
| `_docs/` | архитектура и проектные заметки |

**Стек:** TypeScript везде, Neon Postgres, Vercel (веб + cron), Claude API для
разбора текста, Telegram Bot API + Mini Apps.

## Разработка

```bash
npm install
npm run typecheck
npm test              # vitest, тесты лежат рядом с кодом (*.test.ts)
cd app && npm run dev # мини-апп на моках, Telegram не нужен
```

Мини-апп в dev-режиме поднимает моковое окружение Telegram, поэтому лента,
фильтры и экраны открываются в обычном браузере. Настоящий вход по `initData`
проверяется только на сервере.

Миграции аддитивные и идемпотентные, применяются отдельно от выкладки кода:

```bash
node db/apply.mjs
```

## Секреты

В репозитории только `*.env.example` — имена переменных без значений. Настоящие
ключи живут в локальном `.env` (он в `.gitignore`) и в настройках хостинга.

Раскладка намеренная: у читалки — только сессия Telegram и `INGEST_SECRET`;
строка подключения к базе и токен бота есть только на стороне веба.

## Приватность и правила

Тексты живут в приложении и открываются без установки:
[Политика конфиденциальности](https://korea-jobs-omega.vercel.app/privacy) ·
[Правила программы](https://korea-jobs-omega.vercel.app/rules)

Коротко: мы агрегатор, а не работодатель и не посредник. Контакты из объявлений
показываются с ограничением в сутки, автор объявления может попросить убрать
свою публикацию, аккаунт удаляется по запросу.

## Лицензия

Кода под свободной лицензией нет — репозиторий открыт для чтения.
