# korea-jobs

Бот-агрегатор вакансий для рабочих по Корее: читалка собирает объявления из
телеграм-чатов → ИИ (Claude) раскладывает по полям и убирает повторы → мини-апп
с фильтром по городам → бот шлёт новые подходящие вакансии в личку.

Личный проект (зона Self). План: `../../../.claude/plans/proud-tinkering-meadow.md`.
Архитектура: [`_docs/architecture.md`](./_docs/architecture.md).

## Структура

```
collector/   читалка (Node + GramJS), отдельный worker — НЕ Vercel
api/         Vercel serverless — один catch-all роутер (api/index.ts)
lib/korea/   бизнес-логика бэка (auth, db, bot, ingest, parser, notify, ...)
app/         мини-апп (React + Vite), один Vercel-проект вместе с api
supabase/    схема БД (draft-миграции) + README
_docs/       архитектура и проектные заметки
```

## Секреты и настройки

Только `*.env.example` (имена переменных) в репозитории. Значения — в локальном
`.env` (в `.gitignore`), в репозиторий/логи/чат не попадают (правило №1).
Изоляция по хостам (007): worker-читалка держит только TG-сессию + `INGEST_SECRET`;
ключ от базы (`DATABASE_URL`) и bot-токен — только на Vercel.
