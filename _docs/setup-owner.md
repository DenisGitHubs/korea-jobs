# Что нужно от владельца, чтобы запустить korea-jobs вживую

Пять коротких вещей. Ничего технического знать не надо — где нажать написано.
Всё бесплатно или почти (кроме желания — расходы копеечные). Можно делать не за раз.

Правило про секреты: **значения ключей ты вставляешь сам** (в поля на Vercel или в
локальный файл). В переписку их не пишем — Дэн ключи не показывает и не вводит.

---

## Шаг 1. База данных — Neon через Vercel — ДЕЛАЕМ ВМЕСТЕ, НЕ СЕЙЧАС

**Зачем:** здесь хранятся вакансии, города, пользователи.

**Важно про порядок:** Neon подключается к **уже существующему** проекту на Vercel.
Проекта пока нет (код ещё не выложен), поэтому подключить Neon сейчас **невозможно**.
Это не «сделай сам сейчас», а часть деплоя, который делаем вместе:

> сначала я дописываю код → выкладываю на GitHub → мы создаём проект korea-jobs на
> Vercel → и **только потом** в этом проекте: **Storage → Marketplace → Neon →
> «Create New Neon Account»** (Free, регион ближе) → подключить к проекту.

**Твоё действие на этом шаге:** нажать «создать/подключить Neon» и принять условия
(я подведу к нужному месту).
**Со значением:** ничего вставлять не надо — Vercel сам пропишет строку подключения
(`DATABASE_URL`) в проект.

_Нюанс:_ на бесплатном плане база «засыпает» при простое — первый запрос после паузы
чуть медленнее (полсекунды–две). Для нас некритично.

## Шаг 2. Ключ Claude (это «мозг»-разбор)

**Зачем:** ИИ читает объявление и раскладывает по полям (город, зарплата, телефон).

1. Зайти на **console.anthropic.com**, войти/зарегистрироваться.
2. Раздел **API Keys** → **Create Key**.
3. Скопировать ключ (он показывается **один раз**).

**Что делать со значением:** сохранить у себя; на шаге деплоя вставишь в поле
`ANTHROPIC_API_KEY` в настройках Vercel (я покажу куда).

**Оплата — отдельно от подписки:** Claude **Max** — это про **claude.ai** и Claude Code,
он **не покрывает API**. Наш бот-сервер зовёт именно **API по ключу** — это платится
отдельно, по факту (за токены). В том же кабинете (console.anthropic.com → **Billing**)
нужно один раз добавить способ оплаты или купить кредиты.

_Расход:_ на дешёвой модели (Haiku) разбор тысяч объявлений — центы–доллары. Там же в
Billing можно поставить лимит трат.

## Шаг 3. Ключи для читалки — my.telegram.org

**Зачем:** это «пропуск» для аккаунта-читалки, чтобы он мог читать чаты.
Делается на том аккаунте, который будет читать (не основной — тот, что ты уже используешь).

1. Зайти на **my.telegram.org**, ввести **номер телефона** аккаунта-читалки.
2. Телеграм пришлёт **код** в приложение — ввести его (**этот код вводишь ты**).
3. Открыть **API development tools**.
4. Заполнить любую заглушку: App title — `korea-jobs`, Short name — `koreajobs`,
   Platform — Other. Нажать **Create application**.
5. На странице появятся два значения: **api_id** (число) и **api_hash** (длинная строка).
   Скопировать оба.

**Что делать со значениями:** дать их мне «положить в локальный файл» я не могу (это
секреты) — ты сам вставишь их в файл `collector/.env` в поля `TG_API_ID` и `TG_API_HASH`.
Я подготовлю файл, тебе останется вставить два значения.

## Шаг 4. Один вход читалки (по коду)

**Зачем:** чтобы читалка потом подключалась сама, без кода каждый раз.

1. Я заранее всё установлю, тебе останется запустить **одну команду**:
   `npm run login` (в папке `collector`).
2. Программа спросит номер и **код из Телеграма** — вводишь ты.
3. Она выдаст длинную «строку-сессию». Её ты вставишь в тот же `collector/.env` в поле
   `TG_SESSION`.

Это как пароль от аккаунта — никому не показывай. Ввод кода — только твой (я коды не ввожу).

---

## Шаг 5. Токен бота (скопировать)

**Зачем:** через бота открывается мини-апп и приходят уведомления. Бот уже создан —
**@korea_rabota_bot**.

1. Открыть в Телеграме чат с **BotFather**.
2. Найти сообщение с токеном (строка вида `1234:AA...`). Скопировать.
3. На шаге деплоя вставишь в поле `BOT_TOKEN` на Vercel.

## Порядок (что раньше, что позже)

1. **Сейчас можно** (не зависит ни от чего): Шаг 2 (Claude), Шаг 3 (my.telegram.org),
   Шаг 5 (скопировать токен — просто держи под рукой).
2. **Когда допишу код и выложу на GitHub:** делаем вместе Шаг 1 (Neon) + деплой на Vercel
   (там вставишь ключи).
3. **В конце:** Шаг 4 (вход читалки) — уже когда всё поднято, чтобы сразу пошёл сбор.

Ничего страшного, если сделаешь не по порядку. Как что-то готово — говори, подключаем.
